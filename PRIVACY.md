# Privacy Policy

Effective date: July 27, 2026

RateMySkill is a skills-only plugin distributed as source files. It does not operate a hosted service, create an account, run its own network endpoint, maintain a database, or include developer-operated telemetry.

When a user asks an AI agent to audit a Skill, the agent may inspect files, repositories, URLs, logs, fixtures, transcripts, or other artifacts that the user places in scope. That processing is performed by the user's AI provider and local or hosted execution environment, subject to their settings and privacy terms. RateMySkill does not separately receive or store those artifacts.

The plugin contains no advertising, analytics SDK, authentication system, or sale of personal data. If a user directs the host agent to access a third-party service, that service's privacy terms apply.

Questions or privacy reports can be filed through [GitHub Issues](https://github.com/AmsonntagChow/ratemyskill/issues). Material changes will be published in this repository with an updated effective date.
